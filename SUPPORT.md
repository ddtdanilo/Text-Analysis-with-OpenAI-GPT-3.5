## Bug reports

Use the bug report form and include a minimal synthetic document, exact command,
Python version, package version, operating system, and complete sanitized error
message.

Do not include API keys, private documents, personal data, or confidential API
responses.

## OpenAI account and API support

This project cannot grant model access, change rate limits, resolve billing, or
manage an OpenAI account. Use official OpenAI support for account-specific
issues.

Community support is provided on a best-effort basis without a guaranteed
response time.
